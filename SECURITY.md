# Security Policy

## Reporting a vulnerability

AnimeFlix is an Android anime-discovery project. Please report security issues privately to the repository owner rather than publishing exploit details in a public issue. Do not include account credentials, private data, or unauthorized streaming links in reports. This repository does not promise a formal response-time SLA.

When reporting, include the affected version or commit, a concise description of the impact, and safe reproduction context. Redact tokens, passwords, personal information, and production data.

## Supported versions

Security fixes are handled on a best-effort basis for the current default branch.
